## 2. 수치 분석 (`python3 scripts/bench_analyze.py weekly`)
- 점수 s = ln((E/나이보정+1)/(B+1)), E = 좋아요 + 3×댓글(이벤트 글은 댓글 상한), B = 같은 계정·같은 형식 직전 30개 성숙 게시물 중앙값. s 0.69 = 평소의 2배.
- 코드 효과: 계정 안 중앙값 → 계정 간 √n 가중(ekke.now가 결과를 독점하지 않게), n/(n+10) 수축, 계정 층화 부트스트랩 90% 구간, 다중 비교 보정(BH q=0.1). 판정 '확인/유망/관찰'. 이번 주 데이터만으로 전략을 바꾸지 않는다.
- 표: T1 계정 기준선 / T2 코드 효과 / T3 훅×형식 / T4 이번 주 상·하위 / 급상승 신호(빈도 z≥2 + 성과) / 주제 레이더.
- 한계: 경제 정보형 캐러셀은 저장·공유로 반응해서 좋아요 기반 점수에서 과소평가될 수 있다. 우리 데이터의 (저장+공유)/좋아요 배수로 '저평가 가능' 표시를 붙인다.

## 3. 내용 분석 절차 (Claude가 직접 읽고 판단)
1. **짝 비교(핵심)**: 같은 소주제인데 s가 2배 이상 차이 나는 게시물 짝 3쌍을 찾아 앵글·훅·구조 중 무엇이 달랐는지 한 줄로 쓴다.
2. **시그니처**: 계정별로 최근 100개에 4회 이상, s 중앙값 ≥ ln1.3, 하위 20%에 거의 안 드는 (주제×앵글×구조) 조합이나 시리즈. 초기 가설: ekke=속도형 실사 뉴스, 뉴닉=Q&A 설명, 3프로TV=인물 발언 인용, 바이트=숫자 순위 릴스, 캐릿=세대 트렌드 퀴즈, 롱블랙=브랜드 스토리 문장, 아이즈매거진=사진 주도 컬처. 매주 확인·수정한다.
3. **주제 레이더**: 2개 계정 이상이 다뤘는데 우리가 안 다룸 = 놓친 주제 / 1개 계정만 다뤘는데 s 높음 = 선점 기회 / 모두 다룸 = 다른 앵글 필요.
4. **같은 이슈 다르게 다루기**: 같은 기업·정책이 72시간 안에 여러 계정에 나오면 묶어서 (계정, 게시 지연, 앵글, 훅, 구조, 밀도, s)를 비교하고 "이 이슈에서 반응을 가른 건 ○○"를 한 문장으로 쓴다.

## 4. 주간 리포트 (`playbook/benchmark/<주차>.md`)
1) 요약 3줄 2) 짝 비교 3쌍 3) 시그니처 변화 4) 주제 레이더 5) 같은 이슈 비교 1~2건 6) 제작 지침(이것만 playbook.md에 반영)
- **따라 할 공식(5개 이내)**: `[상황] → [공식] → [근거: 계정·짝 비교·점수] → [정글저글식 적용 예]`. 판정 '확인'·'유망' 또는 짝 비교 근거가 있는 것만.
- **피할 것(3개 이내)**: 하위 20%에 반복해서 나온 조합.
- **다음 주 실험(2개 이내)**: 가설 / A·B / 한 번에 한 요인 / 같은 슬롯 유형에서 번갈아 게시 / 팀당 최소 6개, 최대 3주 / 판정은 우리 인사이트(피드: (저장+공유)/도달, 릴스: 평균 시청 시간/길이·공유/조회) / P(A>B)≥0.8 채택, ≤0.2 폐기.

## 5. 베끼지 않는 기준
가져오는 것은 공식(훅 유형, 구조 순서, 반응 장치 종류, 주제 선택)뿐이다. 금지: 연속 6어절 이상 같은 문장(`caption_check.py`가 벤치마크 첫 줄과 대조), 시리즈 이름·고유 말버릇·캐릭터, 표지 배치·색 조합·폰트 구성, 같은 이슈를 같은 순서·같은 예시로 구성하기. 7인 검토의 법무 항목에서 "우리 말투와 숫자로 다시 썼는가"를 본다.
