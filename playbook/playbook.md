## 캡션 규칙
- 첫 줄: 이모지 + 한 줄 훅 (125자 안에 핵심)
- 이모지 소제목 3개 이내, '-' 항목, ':' 보충, '⇒' 결론, '(* 기준)'
- 끝: 댓글 유도 질문 1개 → '정보 제공 목적·재작성' 표기 → 📰 출처 → 고정 CTA '💸 돈 되는 트렌드, 매일 @junglejuggle'

## 아직 못 하는 것
- 자체 댓글 달기: 토큰에 `instagram_manage_comments` 권한이 없음 → 다음 토큰 갱신 때 권한 추가 요청
- (해결 11.08) 실사 사진 표지: GitHub Actions가 사진을 내려받아 렌더 (render_in_actions)
- (해결 11.08) 릴스 음악: 외부 무료 음원 라이브러리(Jamendo 주간 인기·신곡 + Openverse, CC0/CC BY만) 매주 자동 갱신, 분위기별 순환(최근 12개 릴스 내 재사용 금지), CC BY 크레딧은 캡션에 필수. 라이브러리가 비면 자체 제작 음악.
- (해결 11.08) 실사 사진: 공식 사진 주소 → Openverse → Wikimedia Commons → (키 있으면) Pexels·Unsplash·Pixabay 순으로 자동 탐색, 못 찾으면 그래픽 배경으로 대체해 게시가 막히지 않게 함.
- 실험: 외부 음원 릴스 vs 자체 제작 음악 릴스의 3초 이탈률·평균 시청 시간 비교(2주 후 판정).
