Transcribe audio/video to word-level timestamps, or import an existing transcript (hyperframes transcribe v0.9.36)

USAGE hyperframes transcribe [OPTIONS] <INPUT>

ARGUMENTS

  INPUT    Audio/video file to transcribe, or transcript file to import (.json, .srt, .vtt) (Required)

OPTIONS

            -d, --dir=<dir>    Project directory (default: current directory)                                                                                                                                                                                                                                                                                                                        
      -e, --engine=<engine>    ASR engine: auto (Parakeet if installed and it covers --language, else whisper), parakeet, whisper, or heygen (HeyGen's speech model; bills the HyperFrames plan when signed in, or API credits with a key). Default: auto. Parakeet is more accurate and faster than whisper; install it with `hyperframes models install parakeet`.                                 
                 --speakers    With --engine heygen: label each word with its speaker (Default: false)                                                                                                                                                                                                                                                                                               
        -m, --model=<model>    Whisper model (default: small.en). Options: tiny.en, base.en, small.en, medium.en, small, medium, large-v3                                                                                                                                                                                                                                                            
  -l, --language=<language>    Language code (e.g. en, es, ja). Whisper transcribes as this language; Parakeet, used when it covers it, detects the language itself.                                                                                                                                                                                                                                 
                     --json    Output result as JSON; progress JSON lines go to stderr (Default: false)                                                                                                                                                                                                                                                                                              
                  --to=<to>    Write an srt or vtt caption sidecar: exported from a transcript file, or written after transcribing audio/video                                                                                                                                                                                                                                                       
      -o, --output=<output>    Output path for exported SRT/VTT sidecar                                                                                                                                                                                                                                                                                                                              
            --preserve-cues    Keep each transcript entry as its own caption cue (skip word-level grouping). Use when exporting an already-cued transcript whose entries have no internal spaces, e.g. single-word or CJK captions. (Default: false)                                                                                                                                                 
          --runtime-install    Allow installing the Whisper runtime. Use --no-runtime-install to require an existing runtime; model downloads remain allowed. (Default: true)                                                                                                                                                                                                                        
       --no-runtime-install                                                                                                                                                                                                                                                                                                                                                                          
                 --optional    Treat captions as optional: if whisper-cpp is unavailable, skip and exit 0 instead of failing. For pipelines that continue without captions. (Default: false)                                                                                                                                                                                                         
        --timeout=<timeout>    Whisper spawn timeout in ms. Overrides the duration+model auto-scaled default. Increase on slow CPUs (e.g. emulated arm64/x64, low-power laptops) where whisper.cpp takes many seconds per audio second on medium/large models. Applies to the whisper engine only; Parakeet has a separate fixed timeout. Minimum 5000 (5 s). Env: HYPERFRAMES_TRANSCRIBE_TIMEOUT_MS.
