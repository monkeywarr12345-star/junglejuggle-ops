# 1편 완성 견본: 구독료 새는 거 AI로 찾기 (실험 브랜치, 게시하지 않음)

## 녹화할 것 (내 일, 약 10분)
1. 카드사 앱에서 지난달 이용내역을 복사한다(개인정보·카드번호·가게 이름 중 민감한 건 가린 버전으로).
2. 챗GPT(또는 제미나이) 새 대화를 열고 화면 녹화를 시작한다.
3. 아래 프롬프트 ①을 붙여 넣고 표가 다 나올 때까지 녹화 → ② → ③ 순서로 이어서.
4. 말할 거면: "구독료 정리, 한 시간 걸리던 거 이제 30초" / "명세서 통째로 붙여 넣으면 됨" / "겹치는 건 하나만 남기면 끝".
5. 녹화 파일을 GitHub clips/inbox/ 에 r1.mp4 로 올린다.
주의: 화면에 내 이름·카드번호·전화번호·얼굴(프로필 사진 포함)이 나오지 않게.

## 프롬프트
① 카드 명세서 붙일게. 매달 반복 결제되는 것만 표로 정리하고, 기능이 겹치는 건 표시해 줘.
② 겹치는 서비스를 묶고, 하나만 남긴다면 뭘 남길지 이유와 함께 알려 줘.
③ 해지할 것만 결제일 가까운 순서로 정렬하고, 앱마다 해지 메뉴 위치를 단계별로 알려 줘.
